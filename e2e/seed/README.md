## e2e/seed

Playwright E2Eテストが自己登録したダミー利用者（`e2e_` プレフィックス）を削除する SQL スクリプト。

E2Eテストは事前投入されたシードデータに依存しない（各テストが `POST /api/auth/register` で
自分専用の利用者を都度作成する。[../README.md](../README.md) 参照）。このスクリプトは、
蓄積したそれらの利用者を一括削除するためのものであり、テストの実行そのものには不要
（未実行でもテストは通る）。

### 注意事項

- **ローカルの使い捨て DB 専用**。共有環境・本番相当の環境では絶対に実行しないこと
- 自動実行はされない。`../run.sh` は実行後にこのスクリプトの存在をリマインドするのみで、
  勝手には実行しない（DB を直接操作する破壊的操作のため）

### いつ実行するか

- しばらく E2E を実行し続けて DB に `e2e_%` 利用者が溜まってきたと感じたとき
- タイムライン等を手動確認していて `e2e_` の投稿がノイズになってきたとき

### 実行方法

docker-compose.yml の既定値の場合:

```sh
docker exec -i pen-and-palette-db mysql -uroot -proot pen_and_palette < e2e/seed/cleanup.sql
```
