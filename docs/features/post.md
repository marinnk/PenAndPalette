# F-3 投稿機能

[← 機能一覧に戻る](index.md)

## 1. 概要

利用者が作品を発表する機能です。投稿は「イラスト投稿」「小説投稿」の2種類の形式があり、投稿作成画面でどちらの形式を使うかによって決まります（利用者が種別を別途選ぶボタンではなく、入力する項目そのものが変わります）。イラスト投稿は画像（1〜4枚）が必須で、本文は任意（280文字まで）の短い一言・一場面を想定した形式です。小説投稿はタイトルと本文（4000文字まで）が必須で、まとまった読み物としての作品本文を投稿できる形式です（画像は任意でカバー画像として1枚まで添付できます）。どちらの形式にも、アプリが用意した固定の分類タグを付けられます。自分の投稿は、後から編集・削除できます。

## 2. できること

| # | できること | 内容 |
|---|---|---|
| 1 | 投稿の作成 | イラスト投稿（画像1〜4枚必須、本文任意280文字まで）または小説投稿（タイトル・本文必須、本文4000文字まで、画像任意1枚まで）のいずれかで投稿する。両方とも分類タグを最大5個まで付けられる |
| 2 | 投稿編集 | 自分の投稿の内容（タイトル・本文・画像・分類タグ）を編集する |
| 3 | 投稿削除 | 自分の投稿を削除する（付いているコメント・いいね・かきたいも合わせて削除される） |
| 4 | 投稿表示 | タイムライン・投稿詳細画面で、投稿の種別に応じた内容（イラスト投稿は画像・本文、小説投稿はタイトル・本文・カバー画像）と、分類タグを表示する |

### 2.1 入力項目

投稿は、投稿作成画面でどちらの形式を使うかにより「イラスト投稿」「小説投稿」のいずれかになります（種別は入力項目そのものの違いで決まり、利用者が別途「種別」を選ぶ項目があるわけではありません）。

#### イラスト投稿

| 項目 | 必須／任意 | 内容 |
|---|---|---|
| 画像 | 必須（1〜4枚） | |
| 本文 | 任意 | 280文字まで |
| 分類タグ | 任意（0〜5個） | アプリが用意した固定の一覧から選ぶ |

#### 小説投稿

| 項目 | 必須／任意 | 内容 |
|---|---|---|
| タイトル | 必須 | 100文字まで |
| 本文 | 必須 | 4000文字まで |
| 画像（カバー） | 任意（0〜1枚） | |
| 分類タグ | 任意（0〜5個） | イラスト投稿と同じ固定の一覧から選ぶ |

## 3. 利用できる人

| 状態 | できること |
|---|---|
| 未ログイン利用者 | 利用できない |
| ログイン利用者 | 自分の作品を投稿できる。自分の投稿のみ編集・削除できる |

## 4. 主な使い方の流れ

### 4.1 投稿する

| 手順 | 利用者の操作 | システムの動き |
|---|---|---|
| 1 | タイムライン画面等の「投稿する」から投稿作成画面を開く | 「イラストを投稿」「小説を投稿」の切り替えと、既定の入力欄（イラスト投稿）を表示する |
| 2 | 「イラストを投稿」または「小説を投稿」を選ぶ | 選んだ種別の入力欄（イラスト：画像・本文、小説：タイトル・本文・カバー画像）に切り替える |
| 3 | 必須項目を入力し、任意で分類タグを選ぶ（最大5個） | 入力内容を確認する |
| 4 | 投稿する | 投稿を保存し、タイムラインの一覧の先頭に表示する |

### 4.2 自分の投稿を編集する

| 手順 | 利用者の操作 | システムの動き |
|---|---|---|
| 1 | 自分の投稿の編集操作をする | 既存の内容が入力済みの編集フォームを表示する |
| 2 | 内容を変更し、保存する | 投稿の内容を更新する |

### 4.3 自分の投稿を削除する

| 手順 | 利用者の操作 | システムの動き |
|---|---|---|
| 1 | 自分の投稿の削除操作をする | 削除の確認を表示する |
| 2 | 削除を確定する | 投稿と、それに付いているコメント・いいね・かきたいを削除する |

## 5. 入力できないとき・失敗したときの挙動

| ケース | 挙動 |
|---|---|
| イラスト投稿で画像が1枚も添付されていない | 投稿しない |
| イラスト投稿で画像が5枚以上添付されている | 投稿しない |
| イラスト投稿で本文が280文字を超えている | 投稿しない |
| 小説投稿でタイトルが未入力、または100文字を超えている | 投稿しない |
| 小説投稿で本文が未入力、または4000文字を超えている | 投稿しない |
| 小説投稿で画像が2枚以上添付されている | 投稿しない |
| 分類タグが6個以上選ばれている | 6個目以降は選択できない |
| 画像の形式・サイズが条件を満たさない | 投稿しない |
| 他人の投稿を編集・削除しようとした | 操作できない（自分の投稿のみ編集・削除できる） |

## 6. 今回はやらないこと

- 下書き保存
- 公開範囲の指定（すべての投稿は全利用者に公開される）
- 投稿後の種別変更（イラスト投稿↔小説投稿の切り替え。作成時の種別のまま編集する）
- 小説投稿の章分け・複数話管理（1投稿＝1作品分の本文とする。長編の連載は今回のスコープ外）
- 利用者による分類タグの新規作成（固定の一覧から選ぶのみ。詳細は[分類タグ機能](tag.md)を参照）
