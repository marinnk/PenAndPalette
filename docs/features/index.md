# 機能一覧：PenAndPalette

[← 要件定義書に戻る](../requirements.md)

## 1. 機能一覧表

| 機能ID | 機能名 | 概要 | 関連画面 |
|---|---|---|---|
| F-1 | [ログイン機能](login.md) | 会員登録し、ログイン・ログアウトができる | S01 ログイン画面、S02 新規登録画面 |
| F-2 | [タイムライン機能](timeline.md) | 投稿を新しい順に一覧表示する。全体／フォロー中、イラスト／小説を切り替えられる（イラストはグリッド表示、小説はリスト表示） | S03 タイムライン画面 |
| F-3 | [投稿機能](post.md) | イラスト投稿（画像必須・本文任意280文字まで）または小説投稿（タイトル・本文必須・本文4000文字まで・画像任意）を投稿する。自分の投稿は編集・削除できる | S04 投稿作成画面、S05 投稿詳細画面 |
| F-4 | [コメント機能](comment.md) | 投稿にコメントできる。画像の添付、自分のコメントの編集もできる | S05 投稿詳細画面 |
| F-5 | [いいね機能](like.md) | 投稿にいいねできる | S03 タイムライン画面、S05 投稿詳細画面 |
| F-6 | [リクエスト機能](request.md) | 気になる利用者に、個人宛てで「こういう創作をしてほしい」と送る | S06 リクエスト作成画面、S07 プロフィール画面 |
| F-7 | [フォロー機能](follow.md) | 他の利用者をフォローし、その投稿をタイムラインで追いかける | S07 プロフィール画面、S10 フォロー中／フォロワー一覧画面 |
| F-8 | [プロフィール機能](profile.md) | 利用者のアイコン・自己紹介・投稿一覧を表示する。他の利用者にはリクエストを送れる | S07 プロフィール画面、S08 プロフィール編集画面 |
| F-9 | [ユーザー検索機能](user-search.md) | ユーザー名・表示名で他の利用者を検索する | S09 ユーザー検索画面 |
| F-10 | [かきたい機能](want-to-create.md) | 投稿に対して「自分も創作してみたい」という気持ちを表す | S03 タイムライン画面、S05 投稿詳細画面 |
| F-11 | [分類タグ機能](tag.md) | 投稿に、アプリが用意した固定の分類タグ（最大5個）を付ける。イラスト投稿・小説投稿どちらにも共通の一覧から選ぶ。タイムラインでは選んだタグで投稿を絞り込める | S03 タイムライン画面、S04 投稿作成画面、S05 投稿詳細画面 |

各画面の詳しいイメージは[画面設計](../screen-design.md)を参照してください。

## 2. 機能と登場人物

「〇」はその状態の利用者が使える機能、「−」は使えない機能を表します。

| 機能ID | 機能名 | 未ログイン利用者 | ログイン利用者 |
|---|---|---|---|
| F-1 | ログイン機能（会員登録・ログイン） | 〇 | 〇（ログアウトのみ） |
| F-2 | タイムライン機能 | − | 〇 |
| F-3 | 投稿機能 | − | 〇 |
| F-4 | コメント機能 | − | 〇 |
| F-5 | いいね機能 | − | 〇 |
| F-6 | リクエスト機能 | − | 〇 |
| F-7 | フォロー機能 | − | 〇 |
| F-8 | プロフィール機能 | − | 〇（閲覧・自分の分の編集） |
| F-9 | ユーザー検索機能 | − | 〇 |
| F-10 | かきたい機能 | − | 〇 |
| F-11 | 分類タグ機能 | − | 〇 |

未ログイン利用者は、閲覧を含めいずれの機能も利用できません（会員登録・ログインの完了後に、はじめてタイムライン等へ進めます）。

## 3. 機能間の関連

各機能は「投稿」または「利用者」を中心に結びついています。

| 起点 | 関連する機能 | 関係の内容 |
|---|---|---|
| 投稿（F-3） | コメント（F-4） | 1つの投稿に複数のコメントが付く |
| 投稿（F-3） | いいね（F-5） | 1つの投稿に複数のいいねが付く |
| 投稿（F-3） | かきたい（F-10） | 1つの投稿に複数の「かきたい」が付く |
| 投稿（F-3） | リクエスト（F-6） | リクエストを送るとき、参考にしてほしい投稿として任意で指定できる |
| プロフィール（F-8） | リクエスト（F-6） | 他の利用者のプロフィール画面からリクエストを送る。届いたリクエストは画面共通ヘッダーの通知バッジで確認する |
| フォロー（F-7） | タイムライン（F-2） | フォロー中の利用者の投稿が、タイムラインの「フォロー中」表示に反映される |
| プロフィール（F-8） | 投稿（F-3）・フォロー（F-7） | プロフィール画面に、その利用者の投稿一覧・フォロー中／フォロワー数が表示される |
| ユーザー検索（F-9） | プロフィール（F-8） | 検索結果から、利用者のプロフィール画面に遷移する |
| 投稿（F-3） | 分類タグ（F-11） | 投稿作成時に、固定の分類タグを最大5個まで付けられる |
| 投稿（F-3） | タイムライン（F-2） | 投稿の種別（イラスト／小説）が、タイムラインの種別タブでの絞り込みに使われる |
| 分類タグ（F-11） | タイムライン（F-2） | 投稿に付いた分類タグが、タイムラインの「絞り込み」での絞り込みに使われる |
