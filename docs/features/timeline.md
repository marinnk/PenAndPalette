# F-2 タイムライン機能

[← 機能一覧に戻る](index.md)

## 1. 概要

投稿を新しい順に一覧表示する機能です。全利用者の投稿を表示する「全体」と、フォロー中の利用者（および自分自身）の投稿のみを表示する「フォロー中」を切り替えて閲覧できます。ログイン後、最初に表示されるメイン画面です。

また、「イラスト」「小説」という投稿の種別によるタブ切り替えも、全体／フォロー中の切り替えとは独立してできます。この種別タブは投稿を絞り込むだけで、表示形式（1列の縦リスト）・カードの内容（投稿者・本文・分類タグ・添付画像を全て・いいね数等）はどちらのタブでも同じです。

## 2. できること

| # | できること | 内容 |
|---|---|---|
| 1 | タイムライン表示（全体） | 全利用者の投稿を新しい順に一覧表示する |
| 2 | タイムライン表示（フォロー中） | フォロー中の利用者（および自分自身）の投稿のみを、新しい順に一覧表示する |
| 3 | 表示切り替え（範囲） | 「全体」「フォロー中」をタブ等で切り替えられる |
| 4 | 表示切り替え（種別） | 「イラスト」「小説」をタブ等で切り替えられる。範囲の切り替えとは独立していて、組み合わせて使える |
| 5 | 種別タブによる絞り込み | イラスト／小説どちらのタブも、投稿カードを1列の縦リストで並べる同じ表示形式。種別タブは表示する投稿を絞り込むだけで、レイアウトは変えない |
| 6 | 投稿の要約表示 | 各投稿に、投稿者・本文（または画像）・分類タグ・添付画像（全て）・いいね数・かきたい数・コメント数を表示する（イラスト／小説どちらのタブでも同じ内容を表示する） |
| 7 | 投稿詳細への遷移 | 投稿カードをクリックすると、その投稿の詳細画面に遷移する |
| 8 | 新着投稿の通知 | 他の利用者の新しい投稿を定期的に検知し、画面上部のバナーで件数を知らせる。バナーをクリックすると一覧の先頭に反映される |

## 3. 利用できる人

| 状態 | できること |
|---|---|
| 未ログイン利用者 | 利用できない（ログイン後にのみ到達する画面） |
| ログイン利用者 | 「全体」「フォロー中」どちらも閲覧できる |

## 4. 主な使い方の流れ

### 4.1 タイムラインを閲覧する

| 手順 | 利用者の操作 | システムの動き |
|---|---|---|
| 1 | ログイン後、タイムライン画面が表示される | 既定では「全体」タブの投稿一覧を新しい順に表示する |
| 2 | 「フォロー中」タブに切り替える | フォロー中の利用者（および自分自身）の投稿のみに絞り込んで表示する |
| 3 | 「イラスト」タブに切り替える | イラスト投稿のみに絞り込んで一覧表示する（表示形式は変わらない） |
| 4 | 「小説」タブに切り替える | 小説投稿のみに絞り込んで一覧表示する（表示形式は変わらない） |
| 5 | 投稿をクリックする | その投稿の詳細画面（コメント・いいね・かきたいの状況を含む）に遷移する |

### 4.2 新着投稿を確認する

| 手順 | 利用者の操作 | システムの動き |
|---|---|---|
| 1 | ー | 画面表示中、定期的に新しい投稿がないか確認する |
| 2 | ー | 新しい投稿が見つかった場合、画面上部に固定表示されるバナーで件数を知らせる（一覧には即座に反映しない） |
| 3 | バナーをクリックする | 新着投稿を一覧の先頭に反映し、画面を最上部までスクロールする |

## 5. 入力できないとき・失敗したときの挙動

| ケース | 挙動 |
|---|---|
| 「フォロー中」タブで、誰もフォローしていない・フォロー中の利用者の投稿がまだない | 投稿がない旨を表示する |
| 投稿が1件もない（全体タブ） | 投稿がない旨を表示する |
| 「イラスト」または「小説」タブで、その種別の投稿がまだない | 投稿がない旨を表示する |

## 6. 今回はやらないこと

- 新着投稿の即時反映（一覧への反映は利用者がバナーをクリックしたタイミングのみ。プッシュ型の仕組み（WebSocket等）は使わず、定期的な確認による検知とする）
- ハッシュタグや投稿本文によるタイムラインの絞り込み（今回追加する「イラスト」「小説」の種別タブは、投稿を作成した際の形式による分類であり、本文の内容やハッシュタグによる自由な絞り込みとは異なるため、本項目は引き続き対象外）
- インプレッション数（閲覧数）の表示
- 他利用者による投稿の編集・削除の自動反映（新着投稿の検知の対象外。画面を再読み込みするまで反映されない）
