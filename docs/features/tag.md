# F-11 分類タグ機能

[← 機能一覧に戻る](index.md)

## 1. 概要

投稿（イラスト投稿・小説投稿のどちらも）に、アプリがあらかじめ用意した固定の分類タグを付ける機能です。ハッシュタグのような自由入力ではなく、決められた一覧（オリジナル／二次創作／ファンタジー／SF／ホラー・ミステリーなど12個）から選ぶ形式で、利用者がタグを新しく作ることはできません。1投稿につき0〜5個まで付けられます。

## 2. できること

| # | できること | 内容 |
|---|---|---|
| 1 | タグの選択 | 投稿作成画面で、固定の分類タグ一覧から0〜5個をクリックして選ぶ（選択中のタグは見た目で区別できる） |
| 2 | タグの表示 | タイムライン・投稿詳細画面で、その投稿に付いた分類タグを表示する |
| 3 | タグによる絞り込み | タイムラインの「絞り込み」で分類タグを1つ選ぶ、または投稿カードのタグをクリックすると、そのタグが付いた投稿だけに絞り込む（[タイムライン機能](timeline.md)参照） |

### 2.1 固定の分類タグ一覧（12件、表示順）

1. オリジナル
2. 二次創作
3. ファンタジー
4. SF
5. ホラー・ミステリー
6. 恋愛
7. 日常
8. コメディ
9. アクション
10. ドラマ
11. キャラクターデザイン
12. 風景・背景

## 3. 利用できる人

| 状態 | できること |
|---|---|
| 未ログイン利用者 | 利用できない |
| ログイン利用者 | 自分の投稿にタグを付けられる。他の利用者の投稿のタグは閲覧のみ。タイムラインでタグによる絞り込みができる |

## 4. 主な使い方の流れ

### 4.1 投稿にタグを付ける

| 手順 | 利用者の操作 | システムの動き |
|---|---|---|
| 1 | 投稿作成画面で、分類タグの選択欄を開く | 固定の12個の候補を表示する |
| 2 | 付けたいタグを選ぶ（最大5個） | 選択状態を保持する |
| 3 | 投稿する | 選んだタグを投稿に紐づけて保存する |

### 4.2 タグで投稿を絞り込む

| 手順 | 利用者の操作 | システムの動き |
|---|---|---|
| 1 | タイムラインで「絞り込み」を開く | 固定の12個の分類タグを表示順で並べる |
| 2 | タグを1つ選ぶ（または投稿カードのタグをクリックする） | そのタグが付いた投稿だけにタイムラインを絞り込む |
| 3 | 選択中のタグをもう一度押す | 絞り込みを解除して元の一覧に戻す |

## 5. 入力できないとき・失敗したときの挙動

| ケース | 挙動 |
|---|---|
| タグを1つも選ばない | 投稿できる（タグは任意） |
| タグを6個以上選ぼうとする | 6個目以降は選択できない |
| 絞り込んだタグの投稿が1件も無い | 選んだタグ名を含めて投稿がない旨を表示する |

## 6. 今回はやらないこと

- 利用者によるタグの新規作成・編集・削除（一覧はアプリが固定で用意する）
- タグの複数選択によるタイムラインの絞り込み（1度に選べるタグは1つ。[タイムライン機能](timeline.md)参照）
- タグごとの投稿数の表示
