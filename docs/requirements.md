# 要件定義書：PenAndPalette

[← READMEに戻る](../README.md)

本書は、PenAndPaletteというWebアプリケーションで「何を」「なぜ」作るのかを定めるものです。実装方法（使用する技術・データベースの構造など）は本書では扱わず、[基本設計書](basic-design.md)にまとめています。エンジニアだけでなく、企画・デザインなど非エンジニアの関係者が読むことも想定し、専門用語には説明を添えています。

## 1. プロジェクト概要

PenAndPaletteは、小説（文字書き）とイラスト（絵描き）、それぞれの創作活動をしている人たちを繋ぐ、創作特化のSNS風Webアプリケーションです。学習目的で開発しています。

利用者は、短い文章（280文字まで）と、任意で画像を添えて投稿できます。小説の一場面のような文章もあれば、イラストだけの投稿もあり、形式を限定しません。他の利用者の投稿に「いいね」「かきたい」「コメント」で反応できるほか、本アプリ最大の特徴として、気になる利用者に「こういう創作をしてほしい」という「リクエスト」を個人宛てに送れる仕組みを持ちます。

## 2. 背景・課題

創作活動をしている人たちの間では、しばしば「自分が始めた話にオチを考えてほしい」「この場面をイラストにしてほしい」「このイラストのキャラクターで話を書いてほしい」といった、ジャンルを超えたコラボレーションへの需要があります。しかし、既存の汎用SNSでは、こうした「創作の呼びかけ」を特定の相手に向けて手軽に送る仕組みは用意されていません。

PenAndPaletteは、文章・イラストを区別せず同じ場所に投稿できるようにしたうえで、気になる利用者に直接「こういう創作をしてほしい」とリクエストを送れるようにすることで、この課題に応えます。

## 3. 対象ユーザー

- 小説（文字書き）、イラスト（絵描き）の創作活動をしている人、またそれらの作品を読んで楽しむ「読み専」の人
- 1人の利用者が複数の役割を兼ねることを想定する（役割を固定しない）
- 学習目的のアプリのため、受講生・個人が学習目的で利用することを想定するが、複数の利用者が同時に使うことを前提に設計する

## 4. 提供する価値

| 価値 | 内容 |
|---|---|
| 創作物の発表・反応 | 短い文章や画像を投稿し、いいね・かきたい・コメントで反応をもらえる |
| ジャンルを超えたコラボレーションのきっかけ | 気になる利用者に「こういう創作をしてほしい」とリクエストを送り、応えてもらえる |
| 創作仲間とのつながり | 気になる利用者をフォローし、その人の新しい投稿を追いかけられる |

## 6. 本アプリでできないこと（スコープ外）

以下は、初回バージョンでは対応しません。将来的な拡張候補として記録しておきます。

- ダイレクトメッセージ（DM）。リクエスト機能は特定の相手に1件送る軽量な仕組みであり、DMのような複数回のやり取り（返信・スレッド化）は行わない
- 通知機能（いいね・コメント・リクエストがついたことをお知らせする機能）。届いたリクエストは、宛先の利用者が自分のプロフィール画面を開いたときに確認する
- リクエストの承認・拒否（送るとそのまま相手に見える状態になり、承諾・却下のワークフローは持たない）
- リツイート・リポスト（他人の投稿を自分のタイムラインに転載する機能）
- インプレッション数（閲覧数）の集計・表示
- 投稿本文の全文検索（ユーザー名・表示名によるユーザー検索は対象内）
- 非公開アカウント・ブロック機能

## 7. 他サービスとの違い

PenAndPaletteはX（旧Twitter）に近いタイムライン形式のSNSですが、次の点が異なります。

| 観点 | 一般的なSNS | PenAndPalette |
|---|---|---|
| 投稿できるもの | 短文・画像・動画など汎用的 | 短い文章と画像に特化した創作向けの投稿 |
| 特定の相手への創作の呼びかけ | 基本的になし | リクエスト機能で、気になる相手に直接「こういう創作をしてほしい」と送れる |
| 閲覧数の表示 | インプレッション数を表示することが多い | 表示しない |
| 他人の投稿の転載 | リツイート・リポストがある | 用意しない |

## 8. 用語集

| 用語 | 意味 |
|---|---|
| 投稿 | 利用者が発表する作品・シチュエーションの単位。本文（280文字まで）と、任意で画像（最大4枚）からなる |
| いいね | 投稿への好意的な反応を表すボタン操作 |
| かきたい | 投稿に対して「自分もこれを題材に書いてみたい・描いてみたい」という創作意欲を表すボタン操作。いいねとは別に付けられる |
| コメント | 投稿に対して自由に書き込める返信。画像を添えることもできる |
| リクエスト | 気になる利用者に対して、個人宛てに送る「こういう創作をしてほしい」という依頼。相手のプロフィール画面から送る |
| フォロー | 他の利用者の投稿をタイムラインに表示させるための関係 |
| フォロワー | 自分をフォローしている利用者 |
| プロフィール | 利用者のアイコン・自己紹介・投稿一覧などをまとめて表示する画面 |
