## 1.5 画面共通仕様

- S01・S02（未ログイン時の画面）は、共通ヘッダーを持ちません。
- S03・S05・S07・S09（ログイン後、ヘッダーからいつでも行き来できるメイン画面群）は、共通ヘッダー（検索・プロフィール・届いたリクエストの通知バッジ・ログアウト）を持ちます。ワイヤーフレームはS03のみ詳細に描いていますが、他の画面にも同じヘッダーが表示される想定です。届いたリクエストの通知バッジ（🔔 届いたリクエスト N）は自分宛てのリクエストが1件以上あるときのみ表示し、クリックするとバッジの直下に一覧をドロップダウン表示します（F-6リクエスト機能）。
- S04・S06・S08・S10（他の画面から開く単機能の画面）は、完了操作または[キャンセル]／[戻る]で必ず元の画面に戻る作りのため、共通ヘッダーを持ちません。

### S03 タイムライン画面

「全体／フォロー中」（範囲）と「イラスト／小説」（種別）は互いに独立したタブで、組み合わせて使えます（例：「フォロー中」×「小説」）。種別タブによって投稿カードの並べ方が変わります（カード自体の内容は同じ）。イラストタブは投稿カードを2列のグリッドで並べる表示、小説タブは投稿カードを1列の縦リストで並べる表示です。

#### S03（小説タブの例。全体／フォロー中の切り替えは従来通り）

```
+------------------------------------------------------+
| PenAndPalette         [検索][プロフィール][ログアウト]  |
+------------------------------------------------------+
| [ 投稿する ]                                            |
+------------------------------------------------------+
| ↑ 3件の新しい投稿があります（クリックして表示）           |  ← 新着があるときのみ表示
+------------------------------------------------------+
| [ 全体 ]   フォロー中            全体   イラスト  [ 小説 ] |
+------------------------------------------------------+
| [アイコン] ユーザーA                    2026-08-20 [編集][削除] |
| 【タイトル】波の向こう                                    |
| 本文の冒頭がここに抜粋表示される（〜100文字程度）…          |
| [ カバー画像 ]  （任意）                                   |
| #ファンタジー #オリジナル                                  |
| ♥ いいね 12   ✏ かきたい 6   💬 コメント 3               |
+------------------------------------------------------+
|        （以下、新しい投稿から順に続く）                    |
+------------------------------------------------------+
```

#### S03（イラストタブの例。投稿カードを2列のグリッドで並べる表示）

```
+------------------------------------------------------+
| PenAndPalette         [検索][プロフィール][ログアウト]  |
+------------------------------------------------------+
| [ 投稿する ]                                            |
+------------------------------------------------------+
| ↑ 3件の新しい投稿があります（クリックして表示）           |  ← 新着があるときのみ表示
+------------------------------------------------------+
| [ 全体 ]   フォロー中            全体  [ イラスト ]  小説  |
+------------------------------------------------------+
| [アイコン]ユーザーA 2026-08-20  |  [アイコン]ユーザーB 2026-08-20 |
| 本文…（3行まで、それ以降は…で省略）|  本文…                          |
| #ファンタジー                   |  #SF                            |
| [ 画像（1枚目のみ） ]            |  [ 画像（1枚目のみ） ]            |
| ♥12 ✏6 💬3                    |  ♥3 ✏1 💬0                     |
+------------------------------------------------------+
|        （以下、新しい投稿から順に続く）                    |
+------------------------------------------------------+
```

グリッドの各カードは、小説タブのリストと同じ投稿カード（投稿者・本文・分類タグ・画像・いいね数等）を使う。投稿ごとに本文の長さや添付画像の枚数（1〜4枚）が異なるとカードの見た目が揃わないため、グリッドでは本文を3行までに丸め、画像は1枚目のみを表示することでカードの高さを揃える（本文全文・全ての画像は投稿詳細画面（S05）で確認できる）。カードをクリックすると投稿詳細画面（S05）に遷移する。

| 項目 | 内容 |
|---|---|
| 表示項目 | 投稿者アイコン・名前、投稿日時、分類タグ、いいね数・かきたい数・コメント数、新着通知バナー（従来通り）に加え、「イラスト」「小説」タブ（全体／フォロー中とは独立して切り替えられる）。イラストタブは投稿カードを2列のグリッドで一覧表示、小説タブは投稿カードを1列の縦リストで表示する（カードの内容自体はどちらも同じ） |
| できる操作 | 「全体」「フォロー中」タブの切り替え、「イラスト」「小説」タブの切り替え（範囲の切り替えと組み合わせ可能）、[投稿する]から投稿作成画面を開く、投稿カードクリックで詳細画面へ、利用者名・アイコンクリックでプロフィール画面へ、いいね・かきたいの登録／解除、（自分の投稿のみ）編集・削除、ヘッダーから検索・プロフィール画面へ、新着通知バナーのクリックで一覧の先頭に新着投稿を反映 |
| 遷移先 | [投稿する]→S04／投稿カードクリック→S05／利用者名・アイコン→S07／[編集]→S04／[検索]→S09 |
| 補足 | 新着通知バナーは、画面のスクロール位置によらず常に表示される。複数回の確認で新着投稿が見つかった場合は、バナーをクリックするまで件数が積み上がる。イラストタブのグリッド内の投稿カードをクリックすると投稿詳細画面（S05）に遷移する（全体・フォロー中で共通の投稿クリック導線と同じ） |

### S04 投稿作成画面

投稿種別（イラスト／小説）は、画面上部の切り替えボタンでどちらの形式を使うかにより決まります（利用者が別途「種別」という項目を選ぶわけではなく、入力する項目そのものが変わります）。作成前のみ切り替えでき、入力を始めた後に切り替えると入力内容が失われる旨を確認します。

#### S04（イラスト投稿の場合）

```
+--------------------------------+
|  投稿する                       |
+--------------------------------+
|  [ イラストを投稿 ]  小説を投稿    |  ← 投稿種別の切り替え（作成時のみ、後から変更不可）
+--------------------------------+
|  画像（1〜4枚・必須）             |
|  [ 追加 ][   ][   ][   ]        |
+--------------------------------+
|  本文（任意・280文字まで）         |
|  [_________________________]   |
|  [_________________________]   |
|                          0/280  |
+--------------------------------+
|  分類タグ（任意・最大5個・クリックで選択） |
|  (オリジナル)(二次創作)(ファンタジー)      |
|  (SF)(ホラー・ミステリー)(恋愛)           |
|  (日常)(コメディ)(アクション)(ドラマ)      |
|  (キャラクターデザイン)(風景・背景)        |
+--------------------------------+
|           [キャンセル] [投稿する] |
+--------------------------------+
```

#### S04（小説投稿の場合）

```
+--------------------------------+
|  投稿する                       |
+--------------------------------+
|  イラストを投稿  [ 小説を投稿 ]    |
+--------------------------------+
|  タイトル（必須・100文字まで）      |
|  [_________________________]   |
+--------------------------------+
|  本文（必須・4000文字まで）        |
|  [_________________________]   |
|  [_________________________]   |
|  [_________________________]   |
|                         0/4000  |
+--------------------------------+
|  カバー画像（任意・1枚まで）        |
|  [ 追加 ]                       |
+--------------------------------+
|  分類タグ（任意・最大5個・クリックで選択） |
|  （イラスト投稿と同じ12個の選択肢）        |
+--------------------------------+
|           [キャンセル] [投稿する] |
+--------------------------------+
```

| 項目 | 内容 |
|---|---|
| 表示項目 | 投稿種別切り替え（イラストを投稿／小説を投稿）。イラスト投稿では画像添付欄（1〜4枚必須）と本文入力欄（任意・280文字まで、文字数カウンター付き）。小説投稿ではタイトル入力欄（必須・100文字まで）、本文入力欄（必須・4000文字まで、文字数カウンター付き）、カバー画像添付欄（任意・1枚まで）。どちらの種別でも分類タグの選択欄（タグをクリックして選択・解除する形式、最大5個、12個の固定候補）を表示する |
| できる操作 | 投稿種別の切り替え（作成前のみ。入力を始めた後に切り替えると入力内容が失われる旨を確認する）、タイトル・本文の入力、画像の追加・削除、分類タグの選択（最大5個）、投稿、キャンセル |
| 遷移先 | 投稿完了→元の画面（タイムラインから開いた場合はS03、プロフィール画面から開いた場合はS07） |
| 補足 | 自分の投稿の[編集]から開いた場合は、既存の内容が入力済みの状態で開き、見出し・ボタンが「投稿を編集」「保存する」に変わる。編集時は投稿種別の切り替えはできない（作成時に決まった種別のまま） |
